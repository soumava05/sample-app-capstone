# Sample Todo App - Codebase Analysis

## Application Overview
- **Name:** todo-app (sample-app-capstone)
- **Type:** Monolithic MVC Web Application
- **Language:** Java 21
- **Framework:** Spring Boot 3.3.2
- **UI Rendering:** Server-side (Thymeleaf templates)
- **Persistence:** File-based (JSON files via Jackson)
- **Security:** Spring Security (BCrypt, Form Login, Remember-Me)
- **Port:** 8090
- **Storage Root:** `storage/` directory
